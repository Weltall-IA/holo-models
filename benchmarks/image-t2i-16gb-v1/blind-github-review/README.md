# Blind T2I Review

This folder contains an anonymous visual review set for eight text-to-image cases.

- Each case contains four anonymous images: `A.png`, `B.png`, `C.png`, and `D.png`.
- All individual images are PNG files at 1024x1024 resolution.
- The evaluation is blind: no model identities are included in this folder.
- The source model-to-label mapping is intentionally not included.

## Cases

- T01 — portrait / skin
- T02 — full body / hands
- T03 — multi-person interaction
- T04 — landscape / environment
- T05 — complex cinematic scene
- T06 — spatial / object constraints
- T07 — text rendering
- T08 — long PT-BR prompt

The individual PNGs are the primary review material. The `grids/` directory contains visual aids only.
